## RLAC Archive

CDAD UH-1033 Data and Human Space is a course offered in the Data and Discovery branch of the Core Curriculum at NYU Abu Dhabi. As the field is rapidly changing and we expect it to grow and change over the years, we will archive the markdown files for the key pages (schedule, materials, outcomes, assessment) here. 

These syllabi are provided as open educational resources with a CC BY-SA-NC 4.0 International license. If you reuse them, in part or in whole, please cite them using the suggested citation below.

- [Before 2020](https://wp.nyu.edu/dhs) 
- [Fall 2020](https://sites.google.com/nyu.edu/dhs-f2020)
- [Spring 2021](https://sites.google.com/nyu.edu/dhs-s2021/)
- [Fall 2021](https://sites.google.com/nyu.edu/dhs-f2021) 
- [Fall 2022](https://sites.google.com/nyu.edu/dhs-f22)

With the courses migration to Github Pages in the Fall 2026 semester, subsequent markdown files will be contained within the page archive [here](https://djwrisley.github.io/DHS/).
