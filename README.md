# Data and Human Space, a course at NYU Abu Dhabi (NYUAD)

# This course is part of the Core Curriculum at NYUAD. It has been taught multiple times before, but it changes from term to term. Check out the [archive](https://djwrisley.github.io/DHS/archive/) for other examples of what it has looked like. 

Some hints for this site:

- it has pages (archive, assignments, assignment guidlines, materials, outcomes, rubrics, schedule). If you are a student in the course, the schedule is your reference point for all we are going to do together. 
- it also has posts. These posts include past semesters' materials as well. So check when you are going through that you are on the right semester. That shorthand F26 should be included in every post for the Fall 2026 term. 
- it also has a tag archive. Posts have relevant tags associated with them, so that you can search by tag to get to course materials as well.
